# Archivo de Tests Históricos

Esta carpeta contiene tests que fueron movidos del directorio `backend/` como parte de la limpieza del repositorio. Estos archivos se conservan como referencia histórica pero no se ejecutan en el flujo de desarrollo activo.

## Archivos archivados

### Tests de Flujo UI/Endpoints
- `test_ui_flow_complete.py` - Test completo del flujo UI
- `test_real_endpoints.py` - Test de endpoints reales
- `test_real_ui_flow.py` - Test del flujo real de UI

### Tests de Email/Hooks
- `test_email_hooks_simple.py` - Test simplificado de hooks de email
- `test_ui_email_hooks.py` - Test de hooks de email desde UI

### Tests Funcionales Específicos
- `test_classify_fix.py` - Test de fix específico de clasificación
- `test_immediate_reflection.py` - Test de reflexión inmediata
- `test_orchestrator_first_click_success.py` - Test del orquestador
- `test_first_click_success_final.py` - Test final de primer click exitoso
- `test_server.py` - Test simple del servidor

## Fecha de archivado

Enero 2025 - Limpieza post-migración de módulos Solicitudes/Servicios a Tickets

## Nota

Estos archivos pueden ser útiles como referencia para:
- Entender flujos históricos de desarrollo
- Debugging de problemas similares
- Documentación de fixes específicos

No se recomienda ejecutarlos directamente ya que pueden referenciar módulos o endpoints que ya no existen.
